# Propósito

Este documento registra todas las decisiones relevantes tomadas durante el desarrollo del TFG.

Su objetivo es:

- Mantener la trazabilidad de las decisiones.
- Facilitar la redacción de la memoria.
- Justificar elecciones tecnológicas.
- Evitar contradicciones futuras.
- Registrar alternativas evaluadas.
