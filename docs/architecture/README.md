# Architecture Decision Records (ADR)

## Objetivo

Registrar todas las decisiones arquitectónicas relevantes del proyecto.

---

## Formato

ADR-XXX

- Contexto
- Problema
- Alternativas
- Decisión
- Justificación
- Consecuencias
