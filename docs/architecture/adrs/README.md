# Método de evaluación

Cada alternativa se evalúa mediante una escala ordinal de 1 a 5:

- 1 = Muy deficiente
- 2 = Deficiente
- 3 = Aceptable
- 4 = Bueno
- 5 = Excelente

La puntuación ponderada de cada criterio se calcula como:

Puntuación ponderada = Puntuación × Peso

La puntuación total de una alternativa es:

Total = Σ(Puntuación × Peso)

La alternativa con mayor puntuación total será la candidata preferente.

En caso de empate o diferencias pequeñas, la decisión final podrá apoyarse en criterios cualitativos adicionales documentados en este ADR.
