# ADR-003: Algoritmo de Generación de Setlists

## Estado

Propuesto

## Contexto

SetlistGen debe construir secuencias de pistas que respeten restricciones de duración, BPM, compatibilidad armónica y progresión de géneros.

## Problema

Seleccionar la estrategia de generación de setlists.

## Alternativas

- Algoritmo voraz.
- Búsqueda con restricciones.
- Beam Search.
- Metaheurísticas.
- Combinación de estrategias.

## Decisión

Pendiente de evaluación.

## Justificación

La decisión dependerá del equilibrio entre calidad musical del resultado y coste computacional.

## Consecuencias

Determinará el tiempo de generación, la escalabilidad del sistema y la calidad de las listas producidas.
