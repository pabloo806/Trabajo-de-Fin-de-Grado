Objetivo del proyecto

Desarrollar una aplicación que permita:

- Analizar bibliotecas musicales
- Obtener BPM
- Detectar tonalidad
- Generar automáticamente setlists
- Exportar listas compatibles con Rekordbox

Usuario principal:

DJ semiprofesional o profesional.

Éxito del proyecto:

Generar playlists coherentes sin intervención manual.
