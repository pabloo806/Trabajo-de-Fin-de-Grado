# Base de Datos

## Descripción

Esta carpeta contiene la definición del modelo de datos y recursos relacionados con persistencia.

---

## Objetivos

- Almacenar canciones.
- Almacenar análisis musicales.
- Almacenar setlists generados.
- Mantener trazabilidad.

---

## Entidades principales

### Song

Información de canciones.

### Setlist

Sesiones generadas.

### SetlistTrack

Relación entre canciones y sesiones.
